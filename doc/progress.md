# API Doc 개발 진행 현황

최종 수정일: 2026-11-20

기능 범위·완료 기준·개발 순서는 [개발 기획](plan.md)을 따른다. 이 파일은 전체 상태와 단계별 상세 문서의 진입점이다.

## 기록 기준

- 단계별 파일은 작업에 착수할 때 `progress/번호-주제.md`로 생성하며 기획과 같은 기능 번호를 사용한다.
- 기능별 기록은 상태와 **현재·검증·남은 작업**으로 작성한다. 해당하지 않는 항목은 생략한다.
- 현재 범위·중요한 제한·완료 판단의 검증 근거만 짧게 남긴다. 작업할 때마다 최신 상태로 고쳐 쓰며 누적 일지로 사용하지 않는다.
- 스타일 수치·내부 구현·개별 수정 과정·반복 검사 결과는 기록하지 않는다. 필요한 설계는 설계 문서, 변경 과정은 Git, 세부 검증은 테스트 코드에서 확인한다.
- 완료 기준을 충족한 경우에만 완료로 표시한다. 샘플·메모리 UI의 검증을 실제 파일·DB·HTTP 연동 완료로 간주하지 않는다.
- 상세 문서가 없는 단계는 아래 상태를 하위 기능에 공통 적용하며 예외는 요약에 기능 번호로 명시한다.

| 상태 | 의미 |
| --- | --- |
| 미착수 | 구현 전 |
| 진행 중 | 일부 구현·설계·검증 진행 |
| 검증 대기 | 구현 후 완료 기준 확인 필요 |
| 완료 | 완료 기준 충족과 검증 근거 확인 |
| 결정 필요 | 사용자 결정 또는 기술 검토 필요 |
| 보류 | 합의에 따라 현재 개발 범위에서 제외 |
