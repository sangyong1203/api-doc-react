# 12. UI 구조 및 화면 흐름 선행 구현

[전체 진행 현황](../progress.md) · [개발 기획](../plan.md)

이 단계의 저장·실행은 메모리·샘플 기반이다. UI 완료와 실제 파일·DB·HTTP 연동 완료를 구분한다.

## 12.01 전체 작업 화면 구조

상태: **완료**

- 현재: 컬렉션·API 탭·요청 편집·응답 영역과 반응형 배치 구현.
- 검증: 넓은/좁은 화면 배치·스크롤·탭 이동·미저장 표시 확인. 2026-11-19 사용자 기본 UI 확인.

## 12.02 컬렉션·API 관리 UI

상태: **완료**

- 현재: 컬렉션·폴더·API 추가·수정·삭제·검색과 삭제 영향 확인 구현.
- 검증: 브라우저에서 이름/위치 검증·CRUD·탭/경로 반영·미저장 편집 보존·삭제 취소 확인.
- 남은 작업: 실제 파일 연동은 02~03에서 진행.

## 12.03 요청·응답 UI

상태: **진행 중**

- 현재: Path·Query·Headers·JSON/Multipart·응답 명세·오류 사례 편집, 입력 검증과 세트별 값 분리 구현. 샘플 실행 결과는 실행 당시 입력 복사본을 표시.
- 검증: 브라우저에서 중첩 필드·배열·타입 오류·세트 전환·Multipart 파일 선택 및 입력 보존 확인. 요청 변환·검증·세트 격리·Body 사용 여부 자동 테스트 21건 통과.
- 남은 작업: Body 사용 여부의 브라우저 상호작용 검증. 실제 HTTP·파일 전송은 05에서 연결.

## 12.04 환경·payload 세트 UI

상태: **완료**

- 현재: 환경/변수 편집, API별 세트 추가·이름 변경·삭제·기본 지정과 미저장 전환 확인 구현.
- 검증: 브라우저에서 환경 저장·삭제·중복 검증, 세트별 입력 복원·기본 세트·API 간 격리·전환/삭제 취소 확인.
- 남은 작업: 실제 변수 해석·저장·호출은 04·06에서 연결.

## 12.05 문서·테스트·이력 UI

상태: **진행 중**

- 현재: Docs 편집·문서 미리보기·Excel 생성, API 저장 이력 목록·선택 복원 구현. 이력 복원은 현재 폼에 적용하며 원본 반영에는 저장이 필요. 현재 이력은 메모리 보관.
- 검증: 브라우저에서 이력 목록·이전 값 복원·미저장 표시·덮어쓰기 취소·API 간 격리 확인. 요청·이력 자동 테스트 24건 통과. 문서 미리보기 렌더링·Excel 생성/재읽기 확인.
- 남은 작업: 문서 UI 검증과 테스트 UI는 후속 진행. 문서 출력은 [07](07-documents.md), 이력 영구 저장은 [02.07](02-desktop-workspace.md#0207-sqlite-개인-설정초안저장-이력)에서 연결.
